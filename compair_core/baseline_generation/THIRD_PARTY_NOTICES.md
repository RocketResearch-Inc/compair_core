# Baseline-generation budget-profile notices

The packaged qwen3:14b tokenizer metadata and Ollama template are derived from
the exact model manifest recorded in `docs/baseline-generation-budget-profile-provenance.md`.
They are distributed under Apache License 2.0. The complete upstream license
text is packaged as `qwen3-14b.LICENSE.md`. The derived profile is modified to
contain only tokenizer, framing, qualification, and provenance data; it does
not contain model tensors.

The tokenizer implementation follows behavior in Ollama 0.32.14 and the
Ollama-pinned llama.cpp revision. Their notices follow.
